# Mahjong Beginner and Regional Rules Guide

A source-linked Mahjong learning library maintained by INEAN PLAY for new players, teachers, clubs, and software agents. It covers major named systems and labels regional variation explicitly; no finite guide can represent every household rule.

## Version policy

American Mah Jongg is filed by card year and requires the matching official NMJL card. Japanese riichi states its tournament baseline. Regional pages distinguish documented common features from table-specific scoring.
