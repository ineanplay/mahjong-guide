# Learn Mahjong / 学习麻将

A clear first-session guide, with tile examples and a complete teaching exercise. Named regional rules remain distinct.

从认牌、组合到完整教学练习；清楚区分各地区玩法。

## What you can do / 可以完成什么

Choose a route → recognize groups → try a teaching hand → learn the chosen rules.

选择路线 → 认识组合 → 完成教学牌局 → 学习对应桌规。
