# 第一场麻将：选好规则再上桌

[English](en.md) | [简体中文](zh.md) | [Türkçe](tr.md) | [Deutsch](de.md)

先说清采用哪套规则。麻将包含多种相关玩法，一种玩法的牌型或分值不能直接套用到另一种。本页用于组织教学牌局，不提供统一的万能计分法。

## 选择学习路线

| 路线 | 首先确认 | 继续阅读 |
|---|---|---|
| 日本立直 | 明确规则版本；至少一个役；只有宝牌不构成役 | WRC 2025 入门 |
| 香港玩法 | 牌桌最低番数及结算表 | 香港麻将指南 |
| 美式麻将 | 采用哪个组织的规则、哪一年及对应正版牌例卡 | 美式麻将指南 |
| 台湾十六张 | 手牌数不同；常规结构为五组面子加一对将 | 台湾麻将指南 |

其他地区玩法见仓库目录。先定路线，再选牌和发牌。

## 学会基础组合

| 名称 | 示例 | 记住 |
|---|---|---|
| 顺子 / chow / chi | 三四五筒 | 同一门的三个连续数字 |
| 刻子 / pung / pon | 三张红中 | 三张相同牌 |
| 对子 / 将 | 两张七条 | 两张相同牌 |
| 杠子 / kong / kan | 四张八筒 | 按具体规则声明并补牌 |

十三张体系的基础结构练习：二三四万＋六七八万＋三四五筒＋三张红中＋两张七条，形成四组面子加一对将；没有杠时共十四张。结构成立不等于可以胡牌；美式牌例、特殊牌型和十六张体系要分别判断。

## 第一局怎么教

1. 写明玩法，选出该玩法使用的牌，按它的发牌程序开始。
2. 先练普通摸牌、打牌流程；有人准备吃碰前先讲解。
3. 再加入吃碰杠，说明取得牌的来源、优先级及对手牌的影响。吃碰后不要额外进行一次普通摸牌。
4. 宣布胡牌前核对牌数、允许的结构、起胡条件及相关限制。
5. 用当前玩法的计分依据结算、记录结果，再检查庄家轮换规则。

## 把桌规写下来

记录规则书／牌例卡年份、使用牌张、初始分数、起胡门槛、吃碰规则、流局处理、连庄条件和纠错程序。教学积分与任何奖品安排分别说明。

## 两道自测

- 四组面子加一对将一定能胡吗？**不能。** 还须符合当前玩法的其他条件。
- 港式番数可以直接代入立直的翻符表吗？**不能。** 两者是不同的计分体系。

使用可打印麻将记录表登记约定的分数变动。立直供托等公共积分应与各玩家分数一起登记；表格本身不计算牌型价值。
