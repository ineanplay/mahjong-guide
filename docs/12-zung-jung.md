# Zung Jung Mahjong: Beginner Guide

> **Scope:** International / Hong Kong origin
> **Version:** Use the current Zung Jung scoring table
> **Summary:** A modern scoring system designed to value strategic hand patterns with fewer arbitrary overlaps.

## Purpose and structure

Zung Jung is a modern Mahjong scoring system created by Alan Kwan. The physical
play uses familiar four-player Mahjong procedures and a standard winning shape,
while the published Zung Jung pattern list determines hand value.

## How to learn it

1. Learn the basic draw, discard, and calling procedure.
2. Keep the official pattern table visible.
3. Identify the hand's major pattern before adding compatible smaller patterns.
4. Apply the official combination and exclusion rules.
5. Use the published settlement method rather than importing Hong Kong or MCR
   payments.

## Beginner strategy

Zung Jung rewards deliberate hand development. Connected suited tiles preserve
options, while honors and terminals become valuable when they support a clear
pattern. Avoid exposing a set only for speed if doing so breaks the intended
scoring route.

The official Zung Jung site is the authority for the scoring table and examples.
