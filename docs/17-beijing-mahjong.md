# Beijing Mahjong: Beginner Orientation

> **Scope:** Beijing, China
> **Version:** Local rule family; confirm the host's sheet
> **Summary:** A practical guide to identifying the Beijing rules in use before learning its local scoring vocabulary.

## Scope and reliability

This page describes a regional rule family, not a government or nationwide standard. A city, province, or country label can cover several club, household, and platform variants.

## Commonly documented features

- Beijing Mahjong usually keeps the standard draw, discard, chow, pung, kong, and four-sets-and-a-pair foundation.
- Published and household versions differ on Flowers, minimum requirements, special hands, dealer continuation, and whether particular waiting shapes or self-draw events receive bonuses.
- Players should learn the actual table sheet instead of importing scoring from Chinese Classical, MCR, or a mobile game carrying the Beijing label.

## Confirm before the first deal

- Tiles included
- Minimum hand
- Allowed calls
- Bonus patterns
- Draw and dealer settlement

## Beginner approach

Start with the ordinary draw-and-discard rhythm and four-sets-and-a-pair structure unless the host states otherwise. Ask for one legal winning example and one complete settlement example. Keep local terms beside their definitions, and never declare a win solely because a different app or regional guide accepts the same tile shape.
