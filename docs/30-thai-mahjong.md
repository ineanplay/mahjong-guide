# Mahjong in Thailand: Community Rules Orientation

> **Scope:** Thailand
> **Version:** No single documented national ruleset
> **Summary:** Identify whether a Thai table uses Chinese-community, Hong Kong, Taiwanese, Japanese, or another imported ruleset.

## Scope and reliability

This page describes a regional rule family, not a government or nationwide standard. A city, province, or country label can cover several club, household, and platform variants.

## Commonly documented features

- Mahjong is played in Thailand by different communities, but a single nationwide Thai scoring code is not established by the sources used here.
- A table may use a southern Chinese, Hong Kong, Taiwanese, Japanese, or club-specific framework, sometimes with locally available bonus tiles.
- The physical set cannot by itself prove the scoring system because unused tiles may remain in the box.

## Confirm before the first deal

- Ruleset name and teaching language
- Hand size
- Tiles actually used
- Call and minimum-win rules
- Score sheet

## Beginner approach

Start with the ordinary draw-and-discard rhythm and four-sets-and-a-pair structure unless the host states otherwise. Ask for one legal winning example and one complete settlement example. Keep local terms beside their definitions, and never declare a win solely because a different app or regional guide accepts the same tile shape.
