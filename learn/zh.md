# 麻将：跟着完成一次教学牌局

[English](en.md) · [简体中文](zh.md) · [Türkçe](tr.md) · [Deutsch](de.md)

这页把认牌、摸打、完整牌例和记分连起来。先完成下方明确标注的教学练习，再进入你选择的正式玩法。教学练习不等同于立直、港式、国标或美式麻将规则。

## 1. 认识牌张

三门数字牌是万、条／索、筒／饼，每门1至9，每张四枚，共108张。再加东南西北各四张和中发白各四张，构成常见的136张基础牌。花牌、动物牌、百搭以及哪些牌不使用，取决于玩法；不要只凭牌盒总张数判断规则。

顺子是同一门的连续三张，例如三四五筒；刻子是三张相同牌，例如三张二条；对子是两张相同牌。数字不会从9绕回1，八九一不是顺子。东南西北也不能排成数字顺子。

## 2. 先做一个完整结构

| 组合 | 牌 | 张数 |
|---|---|---:|
| 顺子1 | 二三四万 | 3 |
| 顺子2 | 六七八万 | 3 |
| 顺子3 | 三四五筒 | 3 |
| 刻子 | 二条、二条、二条 | 3 |
| 将 | 七条、七条 | 2 |
| 合计 | 四组面子加一对将 | **14** |

现在拿走一张七条，只剩13张；再取得七条就补齐该结构。这是本课的“还差一张”练习。正式规则还会检查役、番、台、起胡分或其他限制，所以结构成立不代表在任何玩法下都能宣布胡牌。

## 3. 十分钟教学练习：把规则完整写清

为练摸牌、弃牌和结构判断，本练习只用108张数字牌，四人参加，不使用字牌、花牌和百搭；先不吃、碰、杠，也不使用他人的弃牌胡牌。只能自己摸到最后一张完成“四组面子加一对将”。这些是练习约定，不是地区正式规则。

1. 手动将牌背面朝上混匀，每人取13张；选一位先手额外取1张，剩余作为背面朝上的摸牌区。
2. 先手已有14张，检查是否完成；未完成就弃1张，保留13张。
3. 按逆时针轮流。每人摸1张，检查是否完成；未完成就弃1张。
4. 成功者展示14张，其他人逐组核对：门类、连续数字或相同牌、对子、是否重复使用同一张牌。
5. 每局成功者记+1，其他人记0；摸牌区耗尽且无人完成则全员0。共玩4局，每局先手换下一位，最终总分最高者胜，并列就并列。这是教学积分，不涉及真实金额。

开始前把这些约定填在打印包第1页。这样四人即使不打开外部网站，也能完成一场规则明确的入门练习。

## 4. 跟着走一回合

你持有上面牌例去掉一张七条后的13张牌。若摸到七条，检查出四组一对，可以在本练习中结束；若摸到九万且暂时用不上，就把九万打出，仍保留13张。不要先弃再摸，也不要在一次普通回合连续摸两张。

## 5. 学会吃、碰、杠之后再加入

常见四人规则中，吃通常只能用上家弃牌组成顺子；碰用弃牌补成三张相同牌；杠是四张相同牌，要按具体规则声明并补牌。吃碰后通常直接弃牌，不再额外普通摸牌。胡牌、碰杠、吃的优先级及多人同时胡的处理要按所选规则讲清。本节用于理解概念，不把这些操作直接加入第3节练习。

## 6. 正式玩法如何选择

| 玩法 | 接下来必须补上的规则 |
|---|---|
| 日本立直 | 役、门清、振听、宝牌、翻符及支付；宝牌本身不构成役 |
| 香港玩法 | 起胡番数、花牌、番数结算表及封顶 |
| 国标 | 番种及计分限制、起胡分与花牌处理 |
| 台湾十六张 | 不同手牌数、五组一对结构、台数及连庄 |
| 美式麻将 | 采用组织及当年正版牌例卡、交换牌及百搭限制；不能套用四组一对作为所有胡牌标准 |

先记住一种玩法，不把不同玩法的计分表混用。参考资料库提供各玩法的背景，其中英语资料明确标注为英语；本课的教学流程不需要先阅读它们。商业年度牌例卡不在本项目复制。

## 7. 记分与复盘

假设4局分别由A、C、C、无人完成：最终A=1、B=0、C=2、D=0。打印表的每局行填变动值，最终行再相加；不要把累计总分反复相加。

复盘三件事：是否每次都保持正确牌数？是否把混门牌误当顺子？是否把“结构完成”误当成所有正式玩法都能胡？确认这些以后，再逐项学习选定桌规。
